# FP Growth Go 实现示例

这是对应Python `fp_growth_example.py` 的Go实现版本。

## 运行示例

```bash
cd example
go run main.go
```

## 与Python版本对比

| 项目 | Python (mlxtend) | Go实现 |
|------|------------------|--------|
| 牛奶 | 0.7 (7/10) | 0.7 (7/10) ✓ |
| 面包 | 0.7 (7/10) | 0.7 (7/10) ✓ |
| 黄油 | 0.6 (6/10) | 0.6 (6/10) ✓ |
| 鸡蛋 | 0.5 (5/10) | 0.5 (5/10) ✓ |
| 果汁 | 被排除 (2/10 < 0.3) | 被排除 ✓ |

## 说明

- 当前Go实现成功提取了所有频繁单项集
- 组合项集（如{牛奶, 面包}）需要进一步实现FP Growth的完整递归挖掘算法
- 这是Go版本FP Growth的基本工作流程演示
