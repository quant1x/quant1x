# 🚀 CPU 计算性能优化指南


## 🚀 一、核心优化方向分类

| 分类 | 技术名称 | 应用目标 |
|------|----------|----------|
| 控制流优化 | 无分支编程（Branchless） | 避免分支预测失败 |
| 数据访问优化 | 数据对齐、预取、缓存友好的数据结构 | 提高内存访问效率 |
| 指令级并行 | 指令重排、减少依赖链 | 提高 CPU 流水线利用率 |
| 算法优化 | 查表替代计算、数学公式简化 | 减少复杂运算 |
| 向量化 | SIMD（如 SSE/AVX）、NEON | 单指令多数据并行处理 |
| 编译器优化 | 内联函数、常量传播、循环展开 | 利用编译器智能优化 |
| 多核并行 | OpenMP、TBB、std::thread | 利用多核并发计算 |
| 数值精度控制 | 使用 float 替代 double | 减少内存带宽和计算开销 |

---

## 🧠 二、具体优化技术详解（附示例）

### ✅ 1. **无分支编程（Branchless）**

- **原理**：避免使用 `if`, `switch` 等条件跳转指令，防止因错误预测导致流水线清空。
- **实现方式**：
    - 条件表达式（`?:`）
    - 位运算
    - `std::copysign()`
    - `std::clamp()`
- **示例**：

```cpp
double half = std::copysign(5.0, value); // 替代 if (signbit) ...
```

---

### ✅ 2. **查表法替代幂运算（Look-up Table）**

- **适用场景**：重复调用 `pow(10, n)` 或 `log/exp` 等耗时函数。
- **优势**：大幅降低浮点运算开销。
- **示例**：

```cpp
static constexpr double kPowersOf10[] = {
    1e0, 1e1, 1e2, ..., 1e9
};
double nj1 = kPowersOf10[digits + 1];
```

---

### ✅ 3. **向量化（SIMD）**

- **适用场景**：批量处理数组或向量数据。
- **优势**：单条指令可处理多个数据，适合金融、图像、信号处理等领域。
- **示例（伪代码）**：

```cpp
__m128 values = _mm_load_ps(input);
__m128 result = _mm_add_ps(values, some_offset);
_mm_store_ps(output, result);
```

> ⚠️ 注意：适用于大量连续数据操作，不适合单个数值。

---

### ✅ 4. **内联函数（inline）**

- **目的**：减少函数调用开销。
- **建议**：小函数（如 `Decimal`）可加 `inline` 关键字。
- **注意**：现代编译器会自动决定是否内联。

---

### ✅ 5. **常量传播与折叠（Constant Folding）**

- **原理**：编译器提前计算不变表达式。
- **建议**：将常量提取为 `constexpr`，帮助编译器优化。

```cpp
static constexpr double kHalf = 5.0;
```

---

### ✅ 6. **循环展开（Loop Unrolling）**

- **目的**：减少循环控制开销。
- **方法**：手动或编译器自动展开。

```cpp
for (int i = 0; i < N; i += 4) {
    a[i] = b[i] * c[i];
    a[i+1] = b[i+1] * c[i+1];
    a[i+2] = b[i+2] * c[i+2];
    a[i+3] = b[i+3] * c[i+3];
}
```

---

### ✅ 7. **避免不必要的 volatile 和副作用**

- **问题**：`volatile` 会阻止很多优化。
- **建议**：只在 benchmark 中使用，在正式代码中移除。

---

### ✅ 8. **使用 float 替代 double（精度允许）**

- **好处**：占用更少内存，运算更快。
- **注意**：要评估精度误差是否在业务容忍范围内。

```cpp
float Decimal(float value, int digits = 2);
```

---

### ✅ 9. **内存对齐（Memory Alignment）**

- **目的**：提高 SIMD 和缓存效率。
- **方法**：使用 `alignas()`、`posix_memalign()` 等。

```cpp
alignas(16) double data[1024];
```

---

### ✅ 10. **使用编译器优化标志**

- **推荐选项**：
    - `-O2` / `-O3`（GCC/Clang）
    - `/O2` / `/Ox`（MSVC）
- **附加建议**：
    - `-ffast-math`（慎用，可能影响浮点精度）
    - `-march=native`（针对当前 CPU 架构优化）

---

### ✅ 11. **使用 Profiler 工具定位热点**

- **工具推荐**：
    - `perf`（Linux）
    - `VTune`（Intel）
    - `VisualVM` / `dotTrace`（跨平台）
- **用途**：找出真正耗时的函数或语句。

---

## 🔍 三、结合你的项目应用建议

| 场景 | 推荐技术 |
|------|-----------|
| `v1Decimal`（使用 `std::pow`） | ✅ 替换为查表法 |
| 小数位数固定（如 2 位） | ✅ 使用 `float` 替代 `double` |
| 批量处理价格数据 | ✅ 使用 SIMD 或 OpenMP 并行化 |
| 高频调用 `Decimal()` | ✅ `inline` + 常量传播 + 无分支 |
| 金融风控系统 | ❌ 不建议使用 `-ffast-math`，保留精度一致性 |
| 性能测试基准 | ✅ 使用 Google Benchmark + `DoNotOptimize()` |

## 📊 四、总结表格：优化技术对比

| 技术 | 是否推荐 | 适用场景 | 说明 |
|------|----------|----------|------|
| 无分支编程 | ✅✅✅ | 控制流密集型 | 防止预测失败 |
| 查表法 | ✅✅✅ | 幂/指数/三角函数 | 提升速度 |
| SIMD | ✅✅ | 批量数据处理 | 金融/图像/音频 |
| 内联函数 | ✅ | 小函数频繁调用 | 如 `Decimal` |
| 循环展开 | ✅ | 循环体简单 | 谨慎使用 |
| float 替代 double | ✅ | 精度要求不高 | 减少带宽 |
| 编译器优化 | ✅✅✅ | 所有情况 | 必须开启 `-O2` |
| 内存对齐 | ✅ | SIMD / 结构体内存布局 | 提高性能 |
| Profiling | ✅✅ | 所有项目 | 定位瓶颈 |
